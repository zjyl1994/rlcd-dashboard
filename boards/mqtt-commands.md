# MQTT Control Commands Reference

## Topic

```
/rlcd/{device_name}/message
```

---

## Payload

```json
{
    "message": "...",
    "info": "...",
    "timeout": 10,
    "beep": 1
}
```

---

## Fields

### `message`

| Value | Effect |
|-------|--------|
| `"任何文本"` | 在屏幕中间显示 overlay 文本；完整 MQTT JSON payload 上限为 4096 字节 |
| 不传或 `null` | 不显示 overlay，不清除已有显示 |

### `info`

| Value | Effect |
|-------|--------|
| `"多行文本"` | 更新屏幕右上信息面板，每行以 `\n` 分隔，左对齐显示，超长不换行直接溢出裁切 |
| 不传或 `null` | 不更新信息面板，不清除已有内容 |

每行最多 20 个字符（约 60 字节），多余截断，最多 48 行。每行显示约 15 个字符，超出部分溢出裁切（不换行）。超过 5 行时每 10 秒自动翻页。

### `timeout`

| Value | Effect |
|-------|--------|
| `0` | 无限期显示 overlay（需手动/后续消息清除） |
| `1` ~ `180` | overlay 在 N 秒后自动消失 |
| 不传 | 默认 10 秒 |
| `<0` 或 `>180` | payload 被拒绝，消息不生效 |

### `beep`

| Value | Effect |
|-------|--------|
| 不传 | 无提示音 |
| `false` / `0` | 无提示音 |
| `true` / `1` | 播放提示音 1 |
| `2` | 播放提示音 2 |
| `3` | 播放提示音 3 |
| `4` | 播放提示音 4 |
| `5` | 播放提示音 5 |
| `6` | 播放提示音 6 |
| 其他数值 | 无提示音 |

### `agent1` / `agent2`

> 控制 Agent 红绿灯状态（左上区域竖排红绿灯）

| Value | Effect |
|-------|--------|
| 不传 | 不改变，保持当前灯状态 |
| `0` | **全灭** — Agent 无状态，灯全部熄灭 |
| `1` | **GREEN** — Agent 空闲/待命 |
| `2` | **YELLOW** — Agent 正在执行（黄灯闪烁） |
| `3` | **RED** — Agent 故障，需人工处理 |
| `<0` 或 `>3` | 被忽略，不改变当前状态 |

---

## Behaviour Notes

- `message` 和 `info` 可同时传入，两者独立生效
- 设备重启后会自动恢复上一次的 `message` 和 `info` 显示
- 收到新消息会覆盖之前的显示（包括无限期显示的 overlay）
